# Protocolo de Trabajo del Agente — Senior Full Stack

Consulte las reglas detalladas en [.agents/rules/senior_dev_workflow.md](file:///c:/JDV/01_Development/FullStack/NEXODEVSTUDIO/nexo-dev-crm/.agents/rules/senior_dev_workflow.md).

### Resumen del Flujo por Tarea:
1. **Análisis:** Comprender el problema y su impacto a nivel Full Stack.
2. **Consultar Dudas:** Si algo no está claro, preguntar antes de codificar.
3. **Mini-Reporte Previsto:** Mostrar objetivo, archivos involucrados y estrategia técnica antes de aplicar cambios.
4. **Implementación:** Código limpio, robusto, tipado y completo.
5. **Validación:** Comprobación de integridad y funcionamiento.
6. **Actualización:** Siempre debes estar pendiente de las reglas y de este archivo para no perder el contexto; si detectas una regla nueva para el agente pregunta si quieres que la añada a las reglas.
